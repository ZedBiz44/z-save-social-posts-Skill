# Worthiness: what gets saved

Two rules, in priority order. Rule 1 always beats rule 2.

## Rule 1 — The principal said so

If the principal used the agreed save inbox, sent the link for saving, or said "save this," it is
worth saving. No quality judgment, no lane check. This is the highest-trust
signal in the system because the principal already did the filtering.

The usual implementation is a **standing inbox**: a saved collection (or
equivalent) on each platform that the principal drops things into. A
scheduled check files everything new that lands there. Items from the inbox
are filed as kept/reference — never as "needs review."

## Rule 2 — Quality bar for pulls and searches

When the agent goes looking (author timelines, topic searches, backfills),
apply this bar. The principal didn't pre-filter these, so the agent must.

**Cut:**
- Personal-life posts (someone's vacation, family, hot takes about nothing)
- Low-value advertising with no useful advice or reusable creative value
- Gimmicky engagement bait ("comment YES if you agree 👇")
- Signup-bait with no substance behind the hook

**Keep:**
- Posts that teach something concrete
- Posts that demonstrate a tactic in action
- Posts whose structure, copy, or format is worth stealing
- Reference material the principal will actually reuse
- Strong advertising headlines, copy, graphics and formats that qualify as
  useful swipes, including sponsored posts when their substance merits saving

**When in doubt, skip it.** A pull candidate that needs defending isn't
worth filing. Log skips with the reason — never silently drop.

## Discovery scope and categorization

For a pull, first apply the requested source and subject. “Find Alex Brown's
good Facebook-group advice” means that topic from that author, not everything
good on their timeline. “Find Bill Brown's AI graphics tips” is a different
brief. Apply the quality bar within that scope. Use a supplied date range or
quantity; otherwise keep the pass bounded and report what was covered.
Adjust selection to each assignment. Do not hardcode an author's specialty.

Direct saves bypass this discovery filter, including personal items Jack
explicitly requests; file those in Evernote. A link supplied only for a
question or critique is not automatically a save request unless it is in an
agreed save inbox/context. If an explicit save already exists, return the
existing entry and complete missing media rather than making another copy.

Topic lanes (e.g. AI agents, marketing, prompts, tools, automation) decide
*how* something is tagged and filed, not *whether* it's worth keeping.
Define lanes with the principal separately and evolve them as the knowledge
system grows. A post that clears rule 1 or rule 2 but fits no lane gets
filed with its best-fit tags — never rejected for being uncategorized.
